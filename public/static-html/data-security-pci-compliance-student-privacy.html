What to do about it

Start with the record, not the software. Any process around data security pci compliance student privacy only holds if the underlying data is captured once and reused, rather than re-entered in a second spreadsheet or register.

  • Capture the data at the point it is created, once
  • Derive reports from that record instead of maintaining separate ones
  • Give parents visibility so queries arrive with context
  • Reconcile against the ledger, not against a summary total
